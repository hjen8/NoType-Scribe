# 🚀 NoType Cloudflare Worker & iOS 捷徑配置手冊

本模組為 NoType 跨平臺行動端核心中繼服務，專為 iPhone、iPad 等行動裝置打造。

---

## 🌟 核心特色
1. **100% 免費、永久免綁信用卡**：運行於 Cloudflare Workers 免費方案，每日享 100,000 次調用。
2. **三機字典即時同步**：Worker 每次執行時自動從 GitHub 拉取最新 `dictionary.txt` 與 `corrections.json`，電腦新增詞彙，手機秒級生效。
3. **臺灣繁體雙重校正**：結合 Groq Whisper-large-v3-turbo (極速 STT) + Llama 3.3-70B 臺灣語意標點潤飾 + 自癒學習庫二度替換。
4. **iOS 極簡 4 塊積木**：音檔直接傳送，Worker 回傳乾淨純文字，iPhone 捷徑自動秒存剪貼簿。

## 🛠️ 第一階段：Cloudflare 2 分鐘部署教學（免指令、免信用卡）

1. **註冊/登入 Cloudflare**：
   - 前往 [https://dash.cloudflare.com/](https://dash.cloudflare.com/) 登入（只需 Email + 密碼，免填信用卡）。

2. **建立 Worker**：
   - 點擊左側選單的 **「Workers 和 Pages」**。
   - 點擊右上角 **「建立」** (Create) ➔ 選擇 **「建立 Worker」** (Create Worker)。
   - 專案名稱輸入：`notype-api`（或自訂名稱）。
   - 點擊右下角 **「部署」** (Deploy)。

3. **貼上核心程式碼**：
   - 部署完成後，點擊右上角 **「編輯程式碼」** (Edit code)。
   - 將編輯器左側原本的內容全選刪除。
   - 複製本目錄下的 `worker.js` 全部代碼，貼到編輯器中。
   - 點擊右上角 **「儲存並部署」** (Save and deploy)。

4. **設定 Groq API 金鑰**：
   - 回到該 Worker 的 **「設定」(Settings)** ➔ **「變數與機密」(Variables and Secrets)**。
   - 點擊「新增」，變數名稱填入：**`GROQ_API_KEY`**。
   - 數值貼上您的 Groq API Key（例如電腦 `config.json` 裡的 `gsk_...`），點擊儲存並部署。

5. **取得專屬 API 網址**：
   - 回到 Worker 總覽首頁，您會看到一組網址，格式如下：
     `https://notype-api.<你的子網域>.workers.dev`
   - 請將這組網址複製備用！

## 📱 第二階段：iPhone iOS 捷徑配置（4 塊積木）

1. 打開 iPhone 內建的 **「捷徑」App**。
2. 點擊右上角 **「+」** 新增捷徑，頂端名稱改為 **`NoType 語音輸入`**。
3. 依序新增以下 4 個動作：

### 動作 1：錄製音訊
- 搜尋並加入 **「錄製音訊」**。
- 點開箭頭展開詳細設定：
  - 音訊品質：**一般**（或非常高）
  - 開始錄音：**立即**
  - 停止錄音：**點一下時**

### 動作 2：取得 URL 的內容
- 搜尋並加入 **「取得 URL 的內容」**。
- 將 `https://example.com` 替換為您的 Worker 網址，並在尾端加上 `/transcribe`：
  例如：`https://notype-api.yourname.workers.dev/transcribe`
- 點開箭頭展開詳細設定：
  - 方法：改選 **`POST`**
  - 要求標頭：不用設定
  - 要求內文：改選 **`表單`**
  - 點擊「加入新欄位」➔ 選擇 **「檔案」**：
    - 鍵（Key 名稱）：填入 **`file`**
    - 檔案（Value 值）：點擊一下，在下方浮動選單中選擇上面的 **`[錄製的音訊]`**

### 動作 3：拷貝至剪貼簿
- 搜尋並加入 **「拷貝至剪貼簿」**。
- 確認變數為 **`[URL 的內容]`**。

### 動作 4：震動裝置
- 搜尋並加入 **「震動裝置」**（作為完成通知）。

4. 點擊右上角 **「完成」** 儲存！

## ⚡ 第三階段：iPhone 手勢綁定（隨叫隨錄）

### 模式 A：輕點背面兩下（所有 iPhone 皆支援）
1. 打開 iPhone **「設定」** ➔ **「輔助使用」** ➔ **「觸控」**。
2. 滑到最底部，點選 **「輕點背面」** ➔ **「輕點兩下」**。
3. 下滑到「捷徑」分類，勾選 **「NoType 語音輸入」**。

### 模式 B：動作按鈕 Action Button（iPhone 15 Pro / 16 機型）
1. 打開 iPhone **「設定」** ➔ **「動作按鈕」**。
2. 滑動到 **「捷徑」** ➔ 選擇 **「NoType 語音輸入」**。

---

## 🎯 使用體驗
- 在任何輸入框（LINE、微信、備忘錄、瀏覽器）敲兩下手機背面。
- 說出想輸入的句子（包含自訂專有名詞）。
- 點一下停止，手機震動 1 下。
- 游標處長按點「貼上」，修飾好的臺灣繁體字瞬間就位！
